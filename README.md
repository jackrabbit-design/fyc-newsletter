# FYC Club Newsletter

Email newsletter for Falmouth Yacht Club, designed by Jackrabbit.

- `newsletter.html` is the send-ready email. Every image points at a hosted copy in `images/`, so you can paste the HTML straight into any email platform.
- `images/` holds the photos and logo used in the email.

Links written as `{{LIKE_THIS}}` are placeholders to fill in before sending.
